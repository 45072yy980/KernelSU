# 模块

DikSU 用的是 Magisk 模块格式，绝大多数模块可以直接装。

## 安装

三种入口：

1. **本地 zip**：模块页右下角，支持一次选多个，会逐个安装（失败即停）。
2. **仓库**：从配置的模块仓库直接下载安装。
3. **分享**：文件管理器里把 zip 分享给管理器。

安装前会跑一遍[分区保护](/guide/partition-guard)扫描：

- 绿：直接装。
- 黄：列出报告，要你按音量键确认。
- 红：**拒绝安装**，`--force` 也不放行。

## 安装之后

- 模块目录在 `/data/adb/modules/<id>`。
- 新模块默认下次开机生效；越狱模式下用「维护 → 重载模块」立即生效。
- 每个模块可以单独「禁用」（创建 `disable`）或「跳过挂载」（`skip_mount`）。

## 会改 `/system` 的模块

如果模块直接往 `/system`、`/vendor` 里写文件，需要装 **metamodule**（例如 meta-overlayfs）——
内核模块本身只负责 overlay，不接管真实分区写入。

## 模块 WebUI

部分模块自带网页界面（`webroot/` 目录）。在模块详情里能打开，走的是管理器内置的 WebUI 容器。

## 模块配置

带 `module.prop` 里声明的配置项，可以在模块详情里直接改；等价于手改 `config.json`。

## 卸载

- 普通卸载：删掉模块目录，下次开机消失。
- 立即生效：卸载后「重载模块」。
