# 备份与维护

## 备份什么

| 类型 | 内容 | 什么时候用 |
|---|---|---|
| 授权规则 | uid、包名、授权状态、profile | 重装管理器、换机 |
| 模块 | 模块目录及其状态位（`disable`、`skip_mount`） | 换机、批量重装 |

::: warning 不做整机快照
体积不可控，也不属于这个工具该干的事。要整机备份请用 recovery 或专门的备份工具。
:::

## 怎么用

1. 设置 → 备份与恢复 → 新建备份。
2. 备份文件存在管理器自己的私有目录里，不会污染相册或下载目录。
3. 重装/换机后回到同一页，选一份恢复。

恢复前会列出差异（新增几项、覆盖几项），确认后才写入；失败不会留下空壳压缩包
（这是踩过的坑：root 建的包 App 读不了，且失败会残留 zip）。

## 维护

「设置 → 其他功能 → 维护」里有三个动作：

| 动作 | 说明 | 何时用 |
|---|---|---|
| 重载模块 | 重新执行 `post-fs-data`、`services`、`boot-completed` | 越狱激活后、装完模块想立即生效 |
| 软重启 | 只重跑开机流程，不是完整重启 | 模块需要完整开机流程但不想等重启 |
| 带隐藏的软重启 | 先开启隐身模式，再软重启 | 想让管理器在这次开机里就不可见 |

两个重启都会先弹确认框 —— 它们会打断当前正在运行的东西。

## 出问题怎么回退

- 模块装坏了：在「维护」里软重启前先进安全模式（管理器入口），或直接用文件管理器删掉
  `/data/adb/modules/<id>`。
- 授权规则配乱了：恢复上一份备份，或把对应应用开关关掉。
- 完全不放心：卸载管理器 + 删 `/data/adb/ksu`，系统分区从未被改过，重启即恢复原状。
