# 安装与首次启动

## 1. 确认前提

- 设备**不需要**解锁 Bootloader，但内核版本要落在漏洞影响区间内（见[越狱模式](/guide/jailbreak)）。
- 系统本身要能正常开机 —— 越狱只在运行中的系统上做手脚。
- 关闭系统的「MIUI 优化 / 应用完整性校验」之类会拦截安装的开关。

## 2. 安装管理器

从 [Releases](https://github.com/45072yy980/KernelSU/releases) 下载对应 ABI 的 APK（一般手机是 `arm64-v8a`），直接安装。

首次打开会看到首页处于**未激活**状态：内核模块版本显示「—」，导航里的「超级用户」「模块」是灰的。

## 3. 激活越狱

在首页点激活入口，管理器会依次尝试两条链：

1. ghostlock
2. DirtyFrag（前者失败时）

过程中可能黑屏一两秒或提示「正在提权」，属于正常现象。成功后：

- 首页出现**越狱模式**标识；
- 内核模块版本与管理器版本同时可见；
- 导航全部恢复。

::: warning 每次重启都要重新激活
内核模块没有写进 boot 分区，重启后自然就没了。这不是 bug。
:::

## 4. 授权第一个应用

进入「超级用户」，找到要授权的应用并打开开关。系统会弹出 root 请求，确认即可。

命令行验证：

```bash
adb shell su -c id
# uid=0(root) gid=0(root) ...
```

## 5. 装一个模块试试（可选）

「模块」页右下角可以选 zip（支持多选），装完在「维护 → 重载模块」里让它生效，或者直接软重启。

## 卸载

在管理器里点「卸载」只会移除 APK；想彻底清干净：

```bash
su -c 'rm -rf /data/adb/ksu /data/adb/modules /data/adb/ksud'
```

::: tip 先备份
卸载前用「设置 → 备份与恢复」把授权规则和模块列表导出，重装后可以一键恢复。
:::
