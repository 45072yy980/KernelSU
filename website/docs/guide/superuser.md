# 超级用户与应用配置

## 授权

「超级用户」页按应用列出历史请求，开关即授权。授权后：

- 应用调用 `su` 会拿到 root（或按 profile 降级）；
- 关闭开关立即失效，不用重启。

## 按应用配置

点进某个应用，可以调：

| 项 | 作用 |
|---|---|
| 授予 root | 该 uid 是否允许提权 |
| 卸载模块视图（umount） | 这个应用看不到挂载进来的模块（隐藏用） |
| Profile 模板 | 限制能力：只给 shell、限制 SELinux 域、屏蔽特定能力 |
| su 兼容模式 | 对该应用使用兼容的 `su` 行为（老应用常见） |

Profile 的模板在「设置 → 应用配置模板」里统一编辑，改一处，所有引用它的应用一起生效。

## 多用户与工作资料

Android 的多用户/工作资料会让同一个包出现多个 uid。列表里会一并列出，按 uid 分别授权。

## 日志

「设置 → 日志」（sulog）记录每次提权：时间、调用者 uid、命令、结果。排查「谁在偷偷用 root」先看这里。

## 常见问题

::: warning 应用说没有 root，但开关是开的
1. 确认越狱仍是激活状态（重启后要重新激活）。
2. 该应用可能在多用户下的另一个 uid。
3. 应用的 SELinux 域被 profile 限制成 shell 了。
:::
