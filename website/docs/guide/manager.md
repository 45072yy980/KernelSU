# 管理器导览

管理器是唯一入口：授权、模块、特性配置、诊断都在这。下面按页面顺序过一遍。

## 首页

三块信息：

- **状态卡**：越狱模式是否激活、内核模块版本、管理器版本、ksud 版本。
- **快捷入口**：激活越狱、重载模块、打开网页端。
- **设备信息**：内核版本、KMI、ABI。

版本对不上是正常的，原因见[诊断与求助](/guide/troubleshooting#三个版本号为什么对不上)。

## 超级用户

按 uid 列出所有请求过 root 的应用，每个可以单独配置：[超级用户与应用配置](/guide/superuser)。

## 模块

模块列表、安装、更新、卸载，以及模块自己的配置与 WebUI：[模块](/guide/modules)。

## 设置

| 分组 | 内容 |
|---|---|
| 外观 | 三套皮肤（Material 3 / Miuix / Miuix Stock）、强调色、密度 |
| 通用 | 语言、动画、开机自启 |
| 安全 | 隐身模式、计算器解锁码、隐藏应用列表、Keymint 兼容 |
| 工具 | Shizuku、UTS 视图、网络隔离、备份与恢复、维护 |

::: tip 「维护」是个子页面
重载模块、软重启、带隐藏的软重启都在里面，点进去才有 —— 它们是低频且带副作用的操作。
:::

## 网页端（WebUI）

管理器内置一个网页控制台，用 `ksud` 起本地 HTTP 服务，手机浏览器或同一局域网的电脑都能开。
适合批量操作和大屏查看日志；网页端与 App 共用同一份内核状态。

## 版本详情

设置 → 关于 → 版本详情：三份版本并列，外加自检结论。排查问题先看这里。
