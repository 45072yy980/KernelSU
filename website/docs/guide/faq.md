# 常见问题

## 会不会把手机变砖？

提权失败只会停在失败那一步，不写 boot、不写 system。真正的风险来自**模块本身**，所以：

- 分区保护在越狱模式下强制开启，红色级别的写入直接拒绝；
- 装不认识的模块前先做一次[备份](/guide/backup)；
- 出问题先进安全模式，或删掉对应模块目录。

## 重启后 root 为什么没了？

因为内核模块没有写进 boot 分区 —— 这是「不用解锁」的前提。每次开机都要重新激活一次。
详见[越狱模式](/guide/jailbreak)。

## 支持哪些机型？

只要求内核版本落在两条漏洞链的区间内，具体兼容性以实测为准：同一型号不同系统版本的
补丁状态可能不同。

## 能和官方 KernelSU / Magisk 共存吗？

不要。三者都往内核里塞东西，同时装会互相打架。切换前先彻底卸载。

## 为什么管理器叫这个名字，图标却是另一个？

隐身模式会随机化应用名与图标。在「设置 → 安全」里可以调整。

## 网页端打不开

1. 确认 `ksud` 在跑：`ps -A | grep ksud`。
2. 网页端默认只监听本机；同一局域网访问需要网络隔离未把你自己的设备拦住。
3. 端口被占：换一个端口再起。

## 装了模块之后开不了机？

越狱模式下不会出现这种情况（没有改 boot）。如果模块让系统卡在开机动画，通常是模块改了
系统服务相关的内容 —— 长按电源进 recovery，挂载 data 删掉 `/data/adb/modules/<id>` 即可。

## 怎么彻底卸载？

```bash
su -c 'rm -rf /data/adb/ksu /data/adb/modules /data/adb/ksud'
```

再卸载 APK。系统分区从未被改过，重启即恢复原状。

## 为什么文档里的截图和我的界面不一样？

文档只写功能，不跟具体皮肤（Material 3 / Miuix）的排版。三套皮肤功能完全一致。
