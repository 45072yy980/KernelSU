## 五、踩过的坑（省时间）

- **皮肤组件不能混用**：miuix 皮肤下用 Material3 的 Text/AlertDialog 会取到深色字，整屏看不见
- **行必须用项目组件**：自绘 Row 没有图标/箭头/行高，和设置页完全是两种观感
- **`stringResource` 不能放进普通 lambda**（onAdd/onClick 里）—— 编译期就报 "@Composable invocations"
- **`/*` 不能出现在 C 注释里**（-Wcomment 当错误）
- **新增 feature 三处都要改**：Kbuild 登记、`core/init.c` 初始化、`supercall/dispatch.c` 挂 ioctl
  且**记得 include 头文件**，否则隐式声明直接红
- **CI 的 rustfmt / clippy 当错误**：`Self::` 前缀、`map_or_else`、原始字符串 `r##`（JSON 里有 `"#`）
- **ksud 配置走 stdin 而非临时文件**：root 读应用私有目录在 SELinux 下不可靠
- **备份的 payload 要 chown 回 App**：root 建的文件 App 读不了（EACCES），且失败会留下空壳 zip
