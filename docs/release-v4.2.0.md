## 这一版是什么

从 `v4.1.0-ultra` 到这里的 169 个提交：两套全新的内核特性（UTS、网络隔离）、SUSFS 面板整体重构、
分区保护改成安装前三级判定、备份与自检补齐，外加同步上游 25 个提交。

---

## 内核

### 新增：UTS 视图（按 uid 伪装 uname(2)）
- 替换 syscall 表里的 `__NR_uname`，不动 namespace：只改 `uname(2)` 返回值，
  `/proc/sys/kernel/*` 与 sysfs 仍是真值（界面里写明了这个边界）。
- 六个字段 + `field_mask`，三种模式：关闭 / 全局 / 仅指定应用（最多 64 个 uid）。
- 热路径走 RCU：读侧拷快照、写侧换指针 + `synchronize_rcu`，多个进程同时 `uname` 不排队。

### 新增：网络隔离（按 uid 拒绝对外连接）
- 挂 LSM 的 `socket_connect` 与 `socket_sendmsg`：TCP / 已连接 UDP 走前者，
  不 `connect` 直接 `sendto` 的数据报由后者兜住。
- 可放行回环与私网/链路本地（`10/8`、`172.16/12`、`192.168/16`、`100.64/10`、
  `169.254/16`、`fc00::/7`、`fe80::/10`）；`AF_UNIX`、`AF_NETLINK` 从不拦。
- 拒绝返回 `EACCES`；钩子装不上时管理器显示「当前内核不支持」，不假装成功。
- 热点路径只有一次原子读，查表才进 RCU 读区。

### 上游同步（25 个提交）
- **6.6.144 的 `lsm_blob_sizes` 变动**：`selinux_inode` 会失效甚至 panic，改用 `vmlinux.btf`
  查 `lbs_inode` 偏移（新增 `infra/btf_parser.c`、`selinux/inode.c`）。
- SELinux hide 策略解析对齐、标记原始 type datum 减少 symtab 搜索。
- file_wrapper 重开文件时引用计数平衡（泄漏修复）、热点路径去噪、6.19+ 兼容、
  bind-mount 场景的 init.rc 检测、`su_mount_ns` 改走 ksyscall。

### 分区保护
- 删掉运行时拦截（内核 6 个 syscall 钩子 + 管理器子开关）：挂在 `write`/`writev`
  这类极热路径上，收益低、风险高。
- 保护前移到安装前：`ksud` 把模块脚本逐行读一遍，给绿/黄/红三级结论。

## ksud

### SUSFS 客户端重构
- 配置协议改成「先存后应用」：一次 `ksud` 调用下发整份配置，老内核自动回退。
- `status / import / preview / apply / export` 五条子命令，配置与状态存在
  `/data/adb/ksu/susfs/{config.json,state.json}`。

### 分区保护（三级判定）
- 规则从 23 条扩到 39 条，修掉 3 个 P0 与 12 处漏检、8 处误报。
- 红级别单独计预算：截断不能再把红色模块降级成黄色；只读挂载裸设备降级为黄色确认（Y6）。
- 扫描默认开启（管理器关闭时显式传 `KSU_PARTITION_GUARD=0`）。

### 新增命令
- `ksud uts get|set`、`ksud netisolate get|set`，JSON 走 stdin。
- `ksud` 三个 ABI（aarch64 / x86_64 / riscv64）统一用 `c_char` 处理 uapi 的 char 字段。

### 其它修复
- 模块进程被强杀后仍会生效的洞：加标记 + 开机清扫。
- 规则编号撞车、原始字符串转义等一批编译/格式问题。

## 管理器

### SUSFS 面板整体重构
- 六页签（概览 / 设置 / 路径 / 伪装 / 重定向 / 扩展）+ 可滑动 pager + 页签颜色过渡、
  提示条展开动效。
- 草稿模型：改任何一项先落草稿，顶部出现「应用 / 放弃」，点应用才写进内核。
- 功能：隐藏/循环/映射路径、kstat 更新与完整克隆、伪 uname（预填内核事实）、伪 cmdline、
  open 重定向、三个开关、导入导出（先看差异）、恢复上次应用、恢复默认。

### 新增 UTS 视图页 / 网络隔离页
- 按 Shizuku 页的骨架：状态卡 + 小标题分组 + 单选行 + 带图标与搜索的应用选择。
- 应用数量按内核上限截住（UTS 64 / 网络隔离 128），不再整份配置被 `-EINVAL` 拒掉。

### 备份与恢复
- 授权规则与模块可打包备份 / 恢复，恢复前列差异。
- 修掉两个坑：root 建的包 App 读不了（EACCES）、失败会留下空壳 zip（改为写完校验 + 原子改名）。

### 版本详情与自检
- 三份版本（管理器 / 内核模块 / ksud）并排；越狱运行自检 + 一键修复。
- 首页在管理器与 ksud 版本不一致时提示更新，点状态卡直接弹窗。

### 交互与观感
- 尊重系统的「关闭动画」设置：系统动画倍率为 0 时页面切换改瞬切。
- 导航置灰细化到每个入口，不再连带禁用翻页手势与徽标。
- 设置页「工具」组统一图标列；重载模块、软重启、隐藏软重启收进「维护」子页面。
- Material 3 巡检：25 个页面/分支逐行过了一遍，修掉 9 个残留 import 等问题。

## 工程

- CI 拆成轻量门禁（`ci.yml`）+ 完整矩阵（只在发版/手动跑）：push 只编一个 ABI、
  一个 target、一个 KMI；`build-manager` 仍出 8 KMI + 全平台产物。
- `ksud` 的 `cargo check` 增加 x86_64 矩阵 —— bindgen 按目标平台 char 的有符号性
  生成不同类型，只编 aarch64 会把跨 ABI 问题留到发版才暴露。
- 文档站换成 DikSU 自己的 14 页：https://45072yy980.github.io/KernelSU/
- 仓库内保存了 `dsha-diksu-git` 插件源码（2.x），带 APK 护栏与发版编排。

## 安装

下载 `arm64-v8a` 的 APK 直接安装。内核模块已打进 APK，越狱模式下由管理器自己注入，
不需要单独下载 `.ko`。

> 面向**未解锁 Bootloader** 的设备；重启后需要重新激活越狱。风险自负，详见文档站。
